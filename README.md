# Luxury Retail CRM & Clienteling Analytics

An end-to-end customer analytics build for a luxury fashion maison: synthetic
data generation, RFM segmentation, cohort retention, 12-month CLV, an
interactive dashboard, and the Power BI / Tableau / Excel layers a real CRM
team would need alongside it.

**Clone, run one command, and the whole thing rebuilds from a fixed seed.**

```bash
pip install -r requirements.txt
python -m src.run_pipeline
streamlit run dashboard/streamlit_app.py
```

---

## Executive summary

A luxury maison with ten boutiques turned over **€32.19M** across the 24 months
to 30 September 2026, from 9,036 transactions and 2,469 purchasing clients.

The commercial problem is not demand. It is that **12.6% of the active client
book — 311 high-value clients worth €6.85M, a fifth of all revenue — has
stopped buying**, and these are the highest-spending clients in the business by
average order value. Recovering them is worth more than any acquisition
campaign currently running, and unlike a discount it costs nothing in brand
equity.

The analysis finds three levers, all of which protect full-price selling:

1. A lapsed high-value cohort large enough to move the annual number.
2. A measurable gap between the best and worst sales associates at converting
   the same appointment into a sale.
3. A marketing budget weighted towards the channels that return the least.

Every figure in this README is read from
`data/processed/kpi_summary.json`, which is regenerated by the pipeline. None
of them are typed by hand.

## Business context: why luxury clienteling is different

Mass-market retail optimises for traffic and conversion. Luxury optimises for
*relationships*, and the analytics have to follow:

| | Mass-market retail | Luxury clienteling |
|---|---|---|
| Purchase frequency | Weekly to monthly | 1–4 times a year |
| Recency threshold for "lapsed" | 30–60 days | 180+ days |
| Revenue concentration | Long, flat tail | **Top 10% of clients = 42.7% of revenue** |
| Primary growth lever | Promotion and acquisition | Retention and share of wallet |
| Discounting | Routine margin tool | Brand damage; 85.2% of sales here are full price |
| Sales channel | Self-service | Named associate who knows the client |

Three consequences shape every modelling choice in this repository:

**Recency must be measured in months.** A client who last bought five months
ago is behaving normally. Applying a mass-market recency threshold would flag
most of a healthy book as churning and make the segmentation useless.

**Discounting cannot be the retention tool.** The usual answer to a lapsing
customer — send a discount — destroys the pricing integrity that the category
depends on. Every recommendation here is deliberately non-discounting:
appointments, previews, personal contact.

**The associate is the product.** Clienteling revenue is attributed to named
individuals, so coaching is a measurable, repeatable lever rather than a soft
one. That is why the dashboard reports conversion *per associate* and not just
in aggregate.

## Data and methodology

### Synthetic dataset

All data is generated by `src/generate_data.py` from seed 42. No real customer
data is used or required.

| Table | Rows | Grain |
|---|---|---|
| `transactions` | 15,017 | One order line |
| `customers` | 3,400 | One client |
| `products` | 240 | One SKU |
| `boutiques` | 10 | One boutique |
| `associates` | 56 | One sales associate |
| `clienteling_interactions` | 3,972 | One appointment, call or event |
| `campaigns` | 26 | One marketing campaign |

Exported as CSVs and as a single multi-sheet workbook,
`luxury_retail_clienteling_analytics.xlsx`, both in `data/processed/`.

The simulation is built to reproduce the behavioural signature of the category
rather than generic retail noise:

- **Latent client tiers** (VIC 4%, High Potential 14%, Core 30%, Occasional
  52%) drive purchase rate, price point and discount appetite. The long
  Occasional tail is deliberate — most luxury clients buy once and are never
  seen again, and without that tail the retention curve would be implausibly
  flattering.
- **Seasonality** combines a December gifting peak (index 1.58), an August
  trough (0.74), and Saturday-weighted footfall.
- **Restrained markdown**: two private-sale windows plus one outlet boutique
  produce an 85.2% full-price share by value, with VICs the least likely to
  buy on discount.
- **Returns** vary by category and channel — apparel and footwear return far
  more than leather goods, online more than boutique.
- **Appointment-driven demand**: every converted interaction generates an order
  0–13 days later, so the 14-day attribution rule used downstream recovers it.
- **Lapsed high-value clients**: 26% of VIC and High Potential clients are
  assigned a churn date 190–520 days before the snapshot.
- **Boutique targets** are calibrated from realised sales (±12%), so target
  achievement lands in a believable 91–113% band instead of being unrelated to
  the data.

The dataset is anchored to a **fixed snapshot of 30 September 2026** rather than
`today()`, so the published figures stay valid whenever the repository is run.

### RFM methodology

`src/customer_segmentation.py`. Computed over non-returned lines only.

- **Recency** — days from the snapshot to the client's most recent purchase.
- **Frequency** — count of distinct *orders*, not lines. A client buying a coat
  and a scarf in one visit is one transaction.
- **Monetary** — net sales after discount, excluding returns.

Each is scored into 1–5 quintiles (5 best; recency inverted). Clients in the
CRM who have never purchased are excluded — they have no RFM profile and belong
in an acquisition workflow, not a retention one.

Segments are assigned in strict precedence order, so every client gets exactly
one label:

| Order | Segment | Rule | Clients | Revenue share |
|---|---|---|---|---|
| 1 | **Lapsing High-Value** | M ≥ 4 and no purchase in 180 days | 311 | 21.3% |
| 2 | **High-Value Loyal** | M ≥ 4, F ≥ 4, active within 180 days | 552 | 55.8% |
| 3 | **Promising New** | First purchase within 365 days, active within 180 | 532 | 8.8% |
| 4 | **Infrequent** | Everyone else | 1,074 | 14.1% |

Lapsing is tested **first** on purpose. A high-value client going quiet is the
most commercially urgent state in the book, and testing loyalty first would
mask them behind a healthier-sounding label.

### Cohort retention

`src/cohort_analysis.py`. Clients are grouped by the month of their first
purchase and tracked monthly thereafter.

Two corrections matter here, and both suppress numbers that would otherwise
flatter the business:

- **Left-censoring.** Clients who joined before the analysis window are
  excluded. A long-standing client whose first *observed* purchase falls in
  October 2024 is not a new client, and counting them as one loads the earliest
  cohorts with proven repeat buyers.
- **Unobservable cells are blanked, not zeroed.** A cohort acquired three
  months ago has no month-12 retention. Writing zero there would drag the
  average curve down and make retention look like it is collapsing.

The resulting **12-month repeat rate is 60.1%**. That is high against
mass-market benchmarks, and the reason is the denominator: it counts
CRM-identified clients who made a first purchase, not all footfall. Anonymous
walk-ins never enter the database. See *Limitations* for why this statistic is
anchored on join date rather than first-purchase date.

### 12-month CLV

`src/customer_lifetime_value.py`. Deliberately transparent, so a commercial
stakeholder can follow the arithmetic:

```
CLV(12m) = AOV × Expected Orders(12m) × Retention × Gross Margin % ÷ (1 + d)^0.5
```

| Input | Value | Source |
|---|---|---|
| AOV | per client | Observed |
| Expected orders | per client | Annualised frequency, shrunk towards the segment mean |
| Base retention | **60.1%** | Empirical, from the cohort model |
| Gross margin | **69.4%** | Realised, net of markdown, from the product master |
| Discount rate | **10% p.a.** | Assumption, applied at the half-year point |

Output is a **margin** figure, not revenue. Spending to retain a client is a
margin decision, and revenue-based CLV is the most common way these models end
up justifying uneconomic discounts.

| Segment | Clients | Avg 12m CLV | Total |
|---|---|---|---|
| High-Value Loyal | 552 | €9,121 | €5.04M |
| Promising New | 532 | €4,047 | €2.15M |
| Lapsing High-Value | 311 | €3,259 | €1.01M |
| Infrequent | 1,074 | €904 | €0.97M |
| **Total** | **2,469** | | **€9.17M** |

## KPI definitions

Defined once in `src/kpis.py` and imported by the analytics, the dashboard and
the tests, so a number on the dashboard cannot drift from a number in a test.
The DAX in `bi/measures.dax` and the Tableau fields in
`bi/calculated_fields.md` mirror them one for one.

| KPI | Definition | Value |
|---|---|---|
| **Net Sales** | Line value after discount, **excluding returned lines** | €32,194,535 |
| **ATV** (Average Transaction Value) | Net Sales ÷ distinct orders | €3,563 |
| **AUR** (Average Unit Retail) | Net Sales ÷ units sold | €2,278 |
| **Repeat Purchase Rate** | Share of purchasing clients with ≥2 orders in the period | 67.6% |
| **Full-Price Sales Share** | Share of Net Sales at zero discount, **by value** | 85.2% |
| **Campaign ROAS** | Attributed net revenue ÷ campaign spend | 7.09x |
| **Clienteling Conversion Rate** | Interactions followed by a purchase within 14 days | 53.6% (appointments) |
| **Markdown Depth** | 1 − (Net Sales ÷ Gross Sales at list) | 5.0% |
| **Return Rate** | Returned value ÷ all transacted value | 6.6% |

Two definitional choices are worth stating because they are commonly got wrong:

**ATV is measured per order, not per line.** Counting lines understates ATV
precisely for clients who buy multi-piece baskets — the ones you least want to
misread.

**Full-price share is measured by value, not by ticket count.** Discounted
baskets skew towards cheaper product, so the two numbers diverge sharply, and
the commercial question is how much *revenue* is protected from markdown.

## Key findings

### Finding 1 — A fifth of revenue sits with clients who have stopped buying

**Observation.** The single largest commercial exposure in the book is not
weak acquisition; it is high-value attrition that no one is currently
measuring.

**Evidence.** 311 clients — 12.6% of the active book — are classified Lapsing
High-Value: monetary score of 4 or 5, with no purchase for more than 180 days.
They account for **€6,848,543, or 21.3% of Net Sales**. Their average order
value is **€6,233, the highest of any segment** — 50% above High-Value Loyal
clients (€4,169) and nearly triple the Infrequent segment (€2,207). On average
they last purchased **343 days ago**. 218 of them have opted in to contact.

**Implication.** These clients are not low-value churn. They are the most
valuable individual relationships the business has, and they are drifting
without a single triggered intervention. At their own historic average order
value, one recovered purchase each from the 218 contactable clients is worth
**€1.36M** — 4.2% of annual revenue, from clients already known, already
consented, and already proven to buy at full price.

**Action.** Stand up a lapsed-VIC reactivation programme owned by the boutique,
not by marketing. Route the 218 opted-in clients to the associate who last
served them, with a personal appointment invitation and a private preview of
the incoming collection. Deliberately no discount: this cohort buys at the
highest AOV in the business, and a markdown offer would reprice the
relationship permanently. Set a 180-day no-purchase trigger in the CRM so the
list maintains itself. Measure recovered clients and recovered revenue monthly
against the €1.36M ceiling.

---

### Finding 2 — The same appointment is worth €1,186 more with a better associate

**Observation.** Appointments convert far better than any other contact type,
and associate skill — not client quality — explains most of the variation in
what an appointment is worth.

**Evidence.** Across 3,972 logged interactions, appointments convert at
**53.6%** against **30.9% for calls** and 39.1% for events, and generate
**€2,214 of attributed revenue per interaction** versus €1,140 for a call.
Among the 54 associates with at least 15 logged appointments, the spread is
wide: top-quartile associates convert at **60.5%** and realise **€2,794 per
appointment**, while bottom-quartile associates convert at **44.5%** and
realise **€1,608** — a gap of €1,186 on the same unit of effort. The 14
bottom-quartile associates ran 491 appointments between them.

**Implication.** Appointment capacity is the most productive asset in the
boutique and it is being converted inconsistently. This is a coaching gap, not
a traffic gap. Lifting only the bottom quartile to the median revenue per
appointment (€2,057) across the appointments they already run is worth
**€362,301**, or 1.13% of Net Sales — with no additional appointments, no
additional marketing spend and no discount.

**Action.** Two moves. First, rebalance contact mix: the call-heavy portion of
the book should be converted to booked appointments, since a call is worth less
than half an appointment. Second, run structured coaching for the 14
bottom-quartile associates, pairing them with top-quartile performers and
reviewing appointment preparation — client history, pieces pulled in advance,
follow-up discipline. Track conversion per associate monthly on the Clienteling
ROI page, and set a minimum sample of 15 appointments before anyone is ranked,
because small denominators produce dramatic percentages that mean nothing.

---

### Finding 3 — Marketing spend is concentrated in the channels that return least

**Observation.** The marketing mix is inverted relative to its returns, and
owned CRM channels — which also sell more full-price product — are the ones
being under-funded.

**Evidence.** Blended ROAS across 26 campaigns and €463,354 of spend is 7.09x,
but the channel spread is extreme. CRM email returned **29.27x** (€54,454 spend
→ €1,594,096 attributed) and SMS/WhatsApp **12.00x**. Private events returned
**1.81x** on €167,620 — the largest single line of spend, 36% of the budget,
delivering 9% of attributed revenue — and paid social **3.52x**. Separately,
campaign-influenced purchases are **89.3% full-price by value**, against 84.7%
for non-influenced purchases.

**Implication.** The budget is weighted towards the two most expensive,
lowest-returning channels while the highest-returning channel costs almost
nothing to operate. Critically, CRM activity is *not* buying revenue with
discount — campaign-influenced sales skew more full-price than the baseline, so
scaling owned channels improves both revenue and mix. The caveat worth stating
to any stakeholder: a 29x return on a small budget is not evidence that the
budget can grow 29-fold, because email reaches a finite opted-in audience and
returns diminish as frequency rises.

**Action.** Reallocate a defined slice of private-event and paid-social budget
into CRM email and SMS/WhatsApp, and test incrementally rather than shifting
wholesale — email ROAS will fall as volume rises, and the honest question is
where it stops beating 3.52x. Hold private events to a tighter brief: they are
a relationship instrument, so judge them on 12-month CLV movement among
attendees rather than on in-window ROAS, which structurally understates them.
Rebuild consent capture, since only 71% of the database is opted in and
every unconsented client is unreachable through the highest-returning channel.

## Business recommendations

**For boutique teams and client advisors**

1. Work the lapsed high-value list weekly. 218 contactable clients, routed to
   the associate who last served them, personal outreach, no discount.
2. Convert calls into booked appointments. A call returns €1,140; an
   appointment returns €2,214.
3. Prepare every appointment against client history. The gap between the best
   and worst quartile is €1,186 per appointment, and it is closable.
4. Log every interaction. Unlogged clienteling is invisible to attribution and
   cannot be credited to the associate who earned it.

**For CRM and marketing teams**

1. Shift budget from private events and paid social towards CRM email and
   SMS/WhatsApp, testing incrementally.
2. Build a 180-day no-purchase trigger for high-value clients so reactivation
   runs automatically rather than as a quarterly project.
3. Treat consent capture as a revenue metric. 29% of the database cannot be
   reached through the best-performing channel.
4. Judge private events on CLV movement among attendees, not in-window ROAS.

**For commercial leadership**

1. Protect the 85.2% full-price share. Every recommendation above is designed
   to grow revenue without markdown.
2. Report retention by acquisition cohort, not as a single blended rate, so
   improvement is visible while it is happening.
3. Manage the top decile explicitly — 42.7% of revenue sits with 246 clients.

## Documented assumptions

Where the specification was silent, a default was chosen and recorded in
`src/config.py`:

| Assumption | Default | Rationale |
|---|---|---|
| Lapsing threshold | 180 days | Luxury purchase cycles run 1–4 times a year; a mass-market 30–60 day threshold would flag a healthy book as churning |
| High-value definition | Monetary score ≥ 4 | Top two quintiles by spend |
| Loyal definition | Frequency score ≥ 4 | Top two quintiles by order count |
| New-client tenure | 365 days | One full seasonal cycle |
| Clienteling attribution | 14 days, last touch | Matches the Excel and DAX layers exactly |
| CLV horizon | 12 months | Specified |
| CLV retention rate | 60.1% | Estimated from the cohort model, not asserted |
| CLV discount rate | 10% p.a. | Conventional cost of capital |
| CLV basis | Gross margin | Retention spend is a margin decision |
| Snapshot date | 2026-09-30 | Fixed, so published figures never go stale |
| Random seed | 42 | Reproducibility |

## Limitations

Stated plainly, because a model whose weaknesses are hidden is harder to trust
than one whose weaknesses are named.

- **The data is synthetic.** Findings demonstrate analytical method, not real
  market behaviour. The relationships are real consequences of the generative
  assumptions, which is exactly what makes them traceable — and also what makes
  them unsuitable as evidence about any actual brand.
- **Time-window attribution carries a halo.** Crediting any purchase within 14
  days of an interaction also captures purchases that would have happened
  anyway. Measured appointment conversion (53.6%) therefore runs above the true
  generated rate (46.6%). The test suite asserts the direction of this gap and
  bounds its size; a production build would need holdout testing to size
  incrementality properly.

- **Conversion and attribution are deliberately different measures.** An
  interaction *converts* if any qualifying purchase follows it; revenue is
  *attributed* to one interaction per order, last touch. Measuring conversion
  with the attribution rule understates it — an appointment that worked loses
  its conversion if a courtesy call happens to follow it — and reads 47.1%
  rather than 53.6% on this dataset.
- **The 12-month repeat rate is anchored on join date, not first purchase.**
  Anchoring on first purchase looks natural but is biased: requiring 12 months
  of history after the first order silently drops every client whose single
  purchase came late in their tenure — exactly the one-time buyers the metric
  exists to capture. That version of the statistic read 79%; the corrected one
  reads 60.1%.
- **CLV is a 12-month projection, not lifetime value.** It assumes stable
  behaviour and takes no account of macro conditions, assortment changes or
  price increases.
- **Campaign attribution is last-touch.** It credits the final campaign before
  purchase and ignores assists, so upper-funnel channels are systematically
  undervalued. The private-event finding should be read with that in mind.
- **Repeat purchase rate counts CRM-identified clients only.** Anonymous
  walk-in traffic never enters the denominator, which is why the figure sits
  above mass-market benchmarks.

## Setup and reproduction

**Requirements:** Python 3.11+ (tested on 3.12.3).

```bash
# 1. Clone
git clone https://github.com/<your-username>/luxury-retail-clienteling-analytics.git
cd luxury-retail-clienteling-analytics

# 2. Create and activate a virtual environment
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate

# 3. Install pinned dependencies
pip install -r requirements.txt

# 4. Generate all data and analytics (one command, ~25 seconds)
python -m src.run_pipeline

# 5. Run the test suite
python -m pytest tests/ -v

# 6. Launch the dashboard
streamlit run dashboard/streamlit_app.py
```

The dashboard opens at `http://localhost:8501`.

Individual phases can also be run on their own:

```bash
python -m src.generate_data            # Phase 1 only
python -m src.customer_segmentation    # Phase 2a only
python -m src.cohort_analysis          # Phase 2b only
python -m src.customer_lifetime_value  # Phase 2c only
```

### Dashboard sections

1. **Executive performance** — Net Sales, ATV, AUR, repeat rate, full-price
   share and returns, with a monthly revenue and ATV trend.
2. **Customer intelligence** — segment distribution, revenue share, the
   retention cohort heatmap, and a downloadable lapsed high-value call list.
3. **Clienteling ROI** — conversion and revenue per interaction type, plus
   per-associate performance with a minimum-sample filter.
4. **Campaign effectiveness** — ROAS by channel, spend against return, and
   full-price versus discounted mix for campaign-influenced purchases.

Date range, boutique and product category filters apply across all four.
Segments, cohorts and CLV are recomputed against the filtered selection rather
than read from a pre-aggregated file.

### Tests

```bash
python -m pytest tests/ -v
```

21 tests covering RFM arithmetic and score ordering, segment precedence rules,
CLV output shape and economic sanity, the 14-day attribution window, cohort
matrix construction, pipeline reproducibility, and — most importantly — that
**Net Sales excludes returns** at every level, including the edge case where
every line is returned.
